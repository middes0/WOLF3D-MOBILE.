# WOLF3D-MOBILE

Versão experimental para navegador com interface adaptada para celulares, botões de toque e opção de tela cheia.

## Hospedar no Cloudflare Pages

1. Em Cloudflare Pages, crie um projeto conectado a este repositório.
2. Framework preset: **None**.
3. Build command: deixe vazio.
4. Build output directory: `/` (raiz do projeto).
5. Faça o deploy.

## Observações

- Esta versão usa js-dos e os arquivos shareware do projeto original `menene/wolf3d-jsdos` por URLs públicas do GitHub.
- É necessário estar conectado à internet para carregar os arquivos externos.
- Os controles por toque enviam eventos de teclado; o comportamento pode variar conforme o navegador e a versão do emulador. Ainda precisa ser testado em celular real.
- O projeto contém apenas a interface e não redistribui os arquivos binários do jogo.
- Wolfenstein 3D e seus elementos pertencem aos respectivos titulares. Esta adaptação não é afiliada à id Software.

## Controles
- Setas: mover e virar
- Atirar: Ctrl
- Abrir porta: Espaço
- Pausar: Esc
